## local-llm-chat v0.1.0

Initial public release of `local-llm-chat`, a small terminal chat client for
local OpenAI-compatible LLM servers such as `llama-server`.

### Highlights

- Terminal chat with in-memory conversation context
- `instructions.md` support for initial system instructions
- Graceful exit with `/bye`, `/quit`, `/exit`, Ctrl-D, or Ctrl-C
- Configurable server connection with `--port` and `--base-url`
- Better terminal display handling for long lines, Japanese text, emoji, and
  control-sequence stripping
- Optional `prompt_toolkit` input editing with history recall via Up/Down and
  Ctrl-P/Ctrl-N
- Long input support with `/paste` and `/file`
- JSONL output logging via `--log-output`
- Default run script logging under
  `logs/<model>-log-YYYYMMDD-HHMMSS-pid<PID>.jsonl`
- Text PDF reading with `pdftotext`, falling back to `pypdf`
- Optional multimodal PDF reading with `--pdf-images`
- `--version` support

### PDF Support

Text PDFs can be read directly:

```sh
scripts/run.sh --instructions summarize.md paper.pdf
```

For vision-capable `llama-server` models, PDF pages can also be rendered to
images and sent with the extracted text:

```sh
scripts/run.sh --pdf-images --instructions summarize.md paper.pdf
```

### Compatibility Notes

- Conversation context is process-local and is discarded when the client exits.
- The default chat path uses `/v1/completions`.
- `--pdf-images` uses `/v1/chat/completions` with OpenAI-style `image_url`
  content and requires a vision-capable model.
- `prompt_toolkit`, `pypdf`, and `poppler` are optional dependencies installed
  by `scripts/install.sh`.

### Validation

- Added regression coverage for terminal display sanitization and wrapping.
- Added regression coverage for long input via `/paste` and `/file`.
- Added regression coverage for timeout handling and continuation after
  length-limited responses.
- Added regression coverage for text PDF extraction and multimodal PDF image
  request construction.
- All tests pass with:

```sh
python3 -m unittest discover -s tests

```
